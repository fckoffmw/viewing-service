# w2g (watch together)

Сервис для совместного просмотра видеоконтента с чатом.

## Функциональность

- Iframe-плеер из разных источников (VK, YT, RUT)
- Чат через WebSocket (до 2 участников)

## Требования

### Синхронизация просмотра

- Перемотка контента
- Остановка/возобновление воспроизведения
- Синхронизация событий между участниками комнаты (~500мс)
- Любой участник может инициировать событие

### Аутентификация

- Регистрация / авторизация (session-based)

### Профиль

- Ник пользователя
- Аватар
- Смотреть позже (список)
- Заметки о просмотренных видео
- История просмотра

### Страницы

| Страница | Описание |
|----------|----------|
| Главная | Кнопки: «В комнату», «Выбор контента» |
| Выбор контента | Список источников, кнопка установки активного |
| Комната | Видео-плеер + чат |

## Стек

| Компонент | Технология |
|-----------|------------|
| Backend | Go |
| Frontend | HTML, CSS, JS (vanilla) |
| Хранилище | CSV файлы |
| Деплой | Docker Compose |

## Модели данных

### User

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | string | Идентификатор |
| `username` | string | Логин |
| `pass_hash` | string | Хеш пароля |

### Source

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | string | Идентификатор |
| `name` | string | Название |
| `url` | string | URL iframe |

### Room

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | string | Идентификатор |
| `source_id` | string | ID активного источника |

### SyncEvent

| Поле | Тип | Описание |
|------|-----|----------|
| `type` | string | Тип: play/pause/seek |
| `time` | float | Время для синхронизации |
