# w2g (watch together)

Сервис для совместного просмотра видеоконтента с чатом.

## Функциональность

- Iframe-плеер из разных источников (VK, YT, RUT)
- Чат через WebSocket (2 участника)

## Требования (в проработке)

### Синхронизация просмотра
- Возможность перемотать контент
- Возможность остановить проигрывание контента
- Возможность продолжить воспроизведение контента
- Синхронизация ивентов со всеми участниками комнаты в пределах секунды (500мс - ориентир) (асинхронно)
- Возможный инициатор ивента - любой участник

### Аутентификация
- Регистрация / авторизация (session-based)

### Профиль
- Ник пользователя
- Аватарка
- Смотреть позже (список)
- Заметки о просмотренных видео
- История просмотра

### Главная страница
- Кнопка «Перейти в комнату» → глобальная комната
- Кнопка «Перейти к выбору контента» → каталог

### Страница выбора контента
- Список источников (название)
- Кнопка «Установить для просмотра» → установка в глобальную комнату

### Страница просмотра (комната)
- iframe плеер
- Чат справа для пк
- Чат снизу для мобильных устройств

## Стек

| Компонент | Технология |
|-----------|------------|
| Backend | Go |
| Frontend | HTML, CSS, JS (vanilla) |
| Хранилище | CSV файлы |
| Сессии | Redis (планируется) |
| Деплой | Docker Compose / VPS |
| Синхронизация | ws + nats |

## Реализация

### Синхронизация
- Вебсокеты для обмена сообщениями между клиентами и сервером
- NATS для управления подписками на события

## Модели данных

### User

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | string | Идентификатор |
| `username` | string | Логин |
| `pass_hash` | string | Хеш пароля |

### Source

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | string | Идентификатор |
| `name` | string | Название |
| `url` | string | URL iframe |

### Room

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | string | Идентификатор |
| `source_id` | string | ID активного источника |

### Sync event
| Поле | Тип | Описание |
|------|-----|----------|
| `type` | string | Тип ивента: play/pause/seek |
| `time` | string | Время для синхронизации |
