# Чек-лист тестирования перед Pull Request

Данный документ содержит полный список функций для проверки перед отправкой пул-реквеста. Тестирование охватывает все пользовательские сценарии приложения.

## 8. WebSocket протокол

### Отправка сообщений

| Type | Проверка |
|------|----------|
| `chat` | Текст отправляется, получают все кроме отправителя |
| `sticker` | ID стикера отправляется, отображается у всех |
| `play` | Позиция отправляется, синхронизируется |
| `pause` | Позиция отправляется, синхронизируется |
| `seek` | Позиция отправляется, синхронизируется |

### Получение сообщений

| Type | Проверка |
|------|----------|
| `sync` | Новый клиент получает source, playing, position, updated_at |
| `chat` | Сообщение отображается в чате |
| `sticker` | Стикер отображается в чате |
| `play` | Видео запускается |
| `pause` | Видео приостанавливается |
| `seek` | Видео перематывается |
| `source_changed` | source_id и source_url обновляются |
