# VK Video iframe API

Документация по JavaScript API для управления iframe-плеером VK Video.
Взято с https://dev.vk.com/ru/widgets/video

## Параметры iframe

В URL видео можно указать следующие параметры:

| Параметр | Описание |
|----------|----------|
| `oid` | Идентификатор владельца видео: пользователя или сообщества. ID сообщества указывается со знаком минус `-` |
| `id` | Идентификатор видео |
| `hash` | Ключ доступа, выдаётся при экспорте |
| `hd` | Разрешение видео (см. ниже) |
| `t` | Отметка времени начала воспроизведения (формат: `00h00m00s`) |
| `autoplay` | Автоматическое воспроизведение после загрузки (`1` — включить, `0` или не указано — не включать) |
| `loop` | Зациклить воспроизведение видео |
| `js_api` | Использовать JavaScript API для управления виджетом |

### Значения параметра `hd`

| Значение | Разрешение |
|----------|------------|
| `1` | 640 × 360 |
| `2` | 853 × 480 |
| `3` | 1280 × 720 |
| `4` | 1920 × 1080 |

## Подключение JavaScript API

### Шаг 1. Подключите скрипт

```html
<script src="https://vk.com/js/api/videoplayer.js"></script>
```

### Шаг 2. Добавьте `js_api=1` в URL iframe

```html
<iframe 
    src="https://vk.com/video_ext.php?oid=-22822305&id=456241864&hd=2&js_api=1" 
    width="853" 
    height="480" 
    allow="autoplay; encrypted-media; fullscreen; picture-in-picture;" 
    frameborder="0" 
    allowfullscreen>
</iframe>
```

### Шаг 3. Создайте экземпляр видеоплеера

```javascript
const player = VK.VideoPlayer(iframe);
```

## Методы

### Управление воспроизведением

| Метод | Описание |
|-------|----------|
| `play()` | Запускает или возобновляет воспроизведение видео |
| `pause()` | Приостанавливает воспроизведение видео |
| `seek(time: Number)` | Перемещает воспроизведение на позицию `time` (в секундах) |
| `seekLive()` | Перемещает воспроизведение в актуальное состояние прямой трансляции |

### Громкость

| Метод | Описание |
|-------|----------|
| `setVolume(volume: Number)` | Устанавливает громкость (число от `0` до `1`) |
| `getVolume()` | Возвращает значение громкости в диапазоне от `0` до `1` (тип: `float`) |
| `mute()` | Отключает звук (не влияет на настройку громкости) |
| `unmute()` | Включает звук |
| `isMuted()` | Возвращает `true`, если звук отключен, иначе `false` |

### Информация о видео

| Метод | Описание |
|-------|----------|
| `getCurrentTime()` | Возвращает текущее время видео в секундах (тип: `int`) |
| `getDuration()` | Возвращает длительность видео в секундах (тип: `int`) |
| `getQuality()` | Возвращает значение качества воспроизведения видео |
| `getState()` | Возвращает строку с состоянием плеера (см. ниже) |

### События

| Метод | Описание |
|-------|----------|
| `on(event: String, listener: Function)` | Устанавливает обработчик на событие `event` |
| `off(event: String, listener: Function)` | Удаляет обработчик события `event` |

### Lifecycle

| Метод | Описание |
|-------|----------|
| `destroy()` | Отписывает плеер от всех событий и отключает API, но не удаляет iframe |

## Состояния плеера

Метод `getState()` возвращает одно из следующих значений:

| Состояние | Описание |
|-----------|----------|
| `uninited` | iframe с видео не загрузился и плеер не инициализировался |
| `unstarted` | Воспроизведение видео не начиналось |
| `playing` | Видео воспроизводится |
| `paused` | Воспроизведение приостановлено |
| `ended` | Воспроизведение видео завершено |
| `error` | Ошибка воспроизведения видео |

## События

С помощью метода `on(event, listener)` можно подписаться на следующие события:

| Событие | Описание |
|---------|----------|
| `inited` | iframe с видео загрузился и плеер инициализировался |
| `started` | Начало воспроизведения видео |
| `resumed` | Возобновление воспроизведения после паузы |
| `paused` | Приостановка воспроизведения |
| `ended` | Завершение воспроизведения |
| `error` | Ошибка воспроизведения |
| `timeupdate` | Обновление текущего времени видео |
| `volumechange` | Обновление уровня громкости или включение/отключение звука |
| `qualitychange` | Изменение качества проигрываемого видео |
| `adStarted` | Начало проигрывания рекламного ролика |
| `adCompleted` | Окончание проигрывания рекламной секции |

## Объект state

Метод `getState()` возвращает объект со следующей структурой:

```json
{
    "state": "playing",
    "volume": 0.7,
    "muted": "false",
    "time": 321,
    "duration": 600
}
```

| Поле | Тип | Описание |
|------|-----|----------|
| `state` | `string` | Текущее состояние плеера |
| `volume` | `float` | Уровень громкости (0–1) |
| `muted` | `string` | Отключен ли звук (`"true"` или `"false"`) |
| `time` | `int` | Текущее время видео в секундах |
| `duration` | `int` | Общая длительность видео в секундах |
