# w2g: базовые команды

## 1) Запуск локально (Go)

```bash
go mod tidy
go run ./cmd/server
```

Открыть в браузере: `http://localhost:8080`

## 2) Запуск через Docker Compose (для VPS)

```bash
docker compose up -d --build
```

Открыть в браузере: `http://<SERVER_IP>:8080`

## 3) Проверка, что сервис работает

Проверка health endpoint:

```bash
curl http://localhost:8080/healthz
```

Ожидаемый ответ:

```text
ok
```

Проверка чата:
- Открыть сервис в двух вкладках/браузерах.
- Отправить сообщение в одной вкладке.
- Убедиться, что сообщение появилось в другой в реальном времени.

## 4) Остановка сервиса

Если запускали через Compose:

```bash
docker compose down
```

Если запускали через `go run`:
- нажать `Ctrl+C` в терминале.
